# Forge Icons

Forge's default file icons: **Forge Dark** is Catppuccin Icons' Mocha flavour and **Forge Light** its Latte flavour. Only those two flavours are kept, and the themes are renamed.

From [catppuccin/zed-icons](https://github.com/catppuccin/zed-icons) at commit `f695ec0d81d53d6776471c3d3cad702cf11670e3`, unchanged except as said above. MIT licensed (see LICENSE).
